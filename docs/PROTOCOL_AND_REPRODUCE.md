# 问题、冻结设计与复现

研究问题：相同两个片段/两秒预算下，时序覆盖选样能否比随机覆盖更多固定检测器的参考漏检轨迹？这是视频挖掘效用实验，无下游训练。

初始冻结提交 `24395a1` 早于全部模型推理。协议列出数据清单、图像/标注摘要、官方模型权重、处理器设置、源代码、依赖锁、五个配对种子和主指标。试运行目录/首张图仅用于下载成本，其序列0009全部排除。pool/dev/eval各4/4/12个互斥序列；每序列按源帧长度等间隔确定六个不重叠的一秒片段，不看标签或模型失败。原始帧率10Hz，片段内观测5Hz，保留帧→片段→序列身份与时间范围。

主比较：时序facility-location与随机，每序列2片段、2秒；先对五seed配对差取平均，再对12评测序列进行2000次bootstrap，固定seed911205。其他对比均为次要描述，不基于它们改策略。零目标/零失败序列保留记录，对相应无定义比例报告null和有效序列数，不能改成0或100%。固定方法包括随机、均匀时间、外观最远点去重、仅外观facility-location和时序facility-location。

每帧外观为RGB各8-bin直方图（24维），片段取均值；时序部分取相邻帧直方图绝对差的均值。两个向量各自归一化再拼接归一化，以余弦相似度贪心最大化所有候选对已选片段的最大相似度之和。其边际收益递减，倾向覆盖候选集合。它不感知对象语义、运动方向或真实轨迹；没有训练参数。仅外观消融保持目标相同，检验新增时序信息。

参考：原始KITTI Car/Pedestrian标注，框高至少25像素、截断≤0.5、遮挡≤2。固定CPU检测器score≥0.5，同类IoU≥0.5一对一匹配；某轨迹在一个片段至少两个已观测帧漏检，记为参考失败轨迹。评价选中片段覆盖的不同失败轨迹比例；另报告总轨迹覆盖、类别数、重复轨迹比例、外观余弦冗余及成本。未匹配参考目标可能受原始标签质量影响，不是经人工裁决的真车失败；这不是KITTI官方AP/HOTA协议。

“评测集不参与选样”的落实：开发/候选与评测序列完全隔离，无参数搜索；评测时必须将已经冻结的**挖掘策略**应用到未见序列的无标签像素候选，这是测策略本身，并不是用评测标签选训练数据。所有方法的选择名单先不可变落盘，之后才读参考标签。没有模型训练、评测早停或模型选择。

## 从干净环境复现

```bash
uv sync --locked --python 3.12
uv run python scripts/prepare.py
mkdir -p models
curl -fL https://download.pytorch.org/models/fasterrcnn_mobilenet_v3_large_320_fpn-907ea3f9.pth -o models/detector.pth
uv run python scripts/experiment.py verify
uv run pytest -q
uv run python scripts/verify_public.py
uv run streamlit run dashboard.py --server.address 127.0.0.1
```

权重与图像下载后，verify核对全部冻结身份及参考提取、选择与序列统计。`run` 对完整的成功缓存只核验并复用，不计成新推理；错误不会当成成功复用。已发布目录不可覆盖。需要真正重跑模型时，复制仓库到独立目录，先将原reports/frames移到独立归档，保留协议/清单，执行run、analyze并比较稳定结果；耗时字段不要求字节相同。不要对当前已发布证据直接删除或覆写。

首次冻结仅用于新实验目录；不要对已存在的protocol重新freeze。源代码、权重、环境或实际数据变化时拒绝继续。没有付费API或云推理。

## 数据访问与可复制性边界

公开ZIP按ETag、Content-Range、每成员CRC校验分段下载，拒绝服务器返回整包或超限范围；缓存恢复检查实际字节。一次网络超时作为实际失败保留，恢复复用已下载帧。源档案未提供单文件SHA时，本地首次取得的SHA会进入冻结清单；这证明后续一致性，不构成上游真实性签名。

数据是已解码PNG序列，所以检查的是PNG解码失败、完整源索引、缺帧、重复帧和时间边界，不是MP4解码器。相同序列不跨split；完整相同采样视频将触发重复帧检查，但没有证明路线/驾驶日隔离，也不能排除不同片段或近重复路线。

## 跨平台浮点同分问题（公开验收发现）

原始Linux CI逐项重新生成选择名单失败，原生macOS重算通过。新增根目录 `portable_replay.py` 不改冻结算法：对随机/均匀严格重算；对已记录贪心选择逐步检查其边际收益距最大值不超过1e-12，再从原始帧和冻结参考摘要重算全部指标与bootstrap。CI会打印与原生日志不同的近同分重生成名单，不隐藏分歧。不符合贪心最优或指标不一致仍失败。

这验证的是原决策日志在数学目标上的可行性与指标可复核性，**不是跨BLAS位级相同选择的证明**。原始 `scripts/verify_public.py` 与实验源代码保持原样，以保留问题证据。公开跨平台命令为 `uv run python portable_replay.py`；原生完整数据复算仍用 `experiment.py verify`。未来需在新协议中明确量化精度与稳定同分处理，不能回写这轮结果。
